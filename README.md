# 📘 Dasar Pemrograman Bahasa C – Semester 2

Repository ini berisi dokumentasi, catatan, dan latihan untuk mata kuliah **Dasar Pemrograman Bahasa C** semester 2. Project ini dibuat sebagai media pembelajaran untuk memahami konsep dasar pemrograman menggunakan bahasa C.

---

## 📚 Materi yang Dipelajari

- Pengenalan bahasa C
- Struktur dasar program C
- Tipe data dan variabel
- Operator
- Percabangan (if, switch)
- Perulangan (for, while, do-while)
- Array
- Function
- Pointer dasar
